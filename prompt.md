# FlowPilot Landing Page — Codex Build Prompt

## Project goal
Build a polished **React + Vite JavaScript** landing page website for a fictional B2B SaaS product called **FlowPilot**.

FlowPilot is an AI-powered project management tool for small teams. It automatically turns messages, meeting notes, and ideas into organized tasks.

This is a portfolio landing page project. It should look like a real modern SaaS website and demonstrate professional frontend skills.

Do **not** build a real backend, authentication, payments, or real integrations. This is a static, frontend-only landing page with polished UI.

---

## Product summary

### SaaS name
**FlowPilot**

### What it does
FlowPilot uses AI to turn messy conversations, meeting notes, and ideas into organized tasks.

### Target audience
- Startup teams
- Small agencies
- Freelancers
- Remote teams

### Main promise

> Turn messy conversations into clear tasks automatically.

### Main positioning line

> Turn conversations into action. Automatically.

# Visual direction

Make it look like a modern B2B SaaS landing page, not an experimental design.

Use:
- Lots of whitespace
- Large typography
- Rounded cards around 12–16px
- Subtle borders
- One main accent color
- Light background
- Dashboard screenshots/mockups
- Small gradients only where useful

Suggested colors:

```txt
Background: #F8FAFC
Text:       #0F172A
Secondary:  #64748B
Accent:     #6366F1
Cards:      #FFFFFF
Border:     #E2E8F0
```

Font:
- Inter or Geist

Recommended design feeling:
- Clean
- Trustworthy
- Spacious
- Startup SaaS
- Practical
- Polished
